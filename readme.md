# 🔐 AI Chatbot with Secure Authentication

A production-grade backend system built using Flask that provides secure authentication, JWT-based authorization, multi-factor authentication (MFA), and structured logging.

---

## 🚀 Features

- 🔑 User Authentication (Signup/Login)
- 🔐 JWT Token-based Authorization
- 🛡️ Password Hashing for Security
- ⛔ Rate Limiting (Brute-force protection)
- 📲 Multi-Factor Authentication (MFA)
- 📊 Logging & Auditing System
- 🔄 Token Management & Logout
- 🌐 Integrated Frontend (HTML/CSS)

---

## 🏗️ Tech Stack

- Backend: Flask (Python)
- Database: PostgreSQL
- Authentication: JWT (JSON Web Tokens)
- Security: Password Hashing, Rate Limiting
- Frontend: HTML, CSS
- Tools: VS Code, Git, GitHub
